### Описание репозитория
Репозиторий содержит простейший RESTful CRUD по созданию, удалению, просмотру и обновлению пользователей.

#### Полезные файлы
- HW_Infra_Patterns.md - описание ДЗ по Инфраструктурным паттернам
- HW_Prometheus_Grafana.md - описание ДЗ по Prometheus и Grafana
- mychart/kuber-help.md - инструкция по запуску приложения
